# そば菓子 杉なみ — sugi-nami

長野県戸隠の古民家で、そば粉の菓子だけを出す店の Web サイト。

> **このサイトは架空の店舗です。** ポートフォリオとして制作したもので、実在する店舗・
> 住所・連絡先ではありません。実在店と誤認されないよう、全ページのフッタ・お品書き・
> 略図・構造化データの四箇所でその旨を明示しています。

本番: https://sugi-nami.vercel.app

## 何を見せる作品か

写真素材を一枚も使わずに、飲食店のブランドサイトが成立するかを試している。

- **図像はすべて SVG** — 杉並木・そばの実・そばの花・雪輪・古民家の切妻・道のりの略図。
  乱数を使わず式で形を決めるので、静的書き出しと再描画で必ず同じ絵になる
- **配色は古民家の内側から** — 白いカフェサイトではなく、障子ごしの光と行灯の色で組む
- **情報の出所をひとつに** — 営業時間は [`src/data/shop.ts`](src/data/shop.ts)、
  お品書きは [`src/data/menu.ts`](src/data/menu.ts) だけが持つ。
  ヘッダ・フッタ・アクセスページ・構造化データはすべてそこから組み立てる
- **JS が無くても全文が読める** — 絞り込みは「除く」方向にだけ効くので、
  何も選んでいない状態(= サーバが描いた HTML)がそのまま正しいお品書きになる

## 構成

| ルート | 中身 |
|---|---|
| `/` | 表・今月の菓子・店のこと・道のりの要約 |
| `/menu` | お品書き(通年 7 品 + 季節 8 品)、アレルゲンの絞り込み |
| `/access` | 道のりの略図、行き方、営業、建物のこと |
| `/opengraph-image` | OG 画像(ビルド時に一度だけ焼く) |

## そばアレルギーの扱い

全品にそば粉が入る店なので、**そばは品ごとに書かない**。書き忘れた品が安全に見えて
しまうため、店全体の注意書き一本に寄せている。品ごとに持つのは「そば以外に何が
入るか」だけ。この設計は [`src/data/menu.test.ts`](src/data/menu.test.ts) で固定してある。

## 開発

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # データと構造化データの検査(23 件)
pnpm typecheck
pnpm build      # out/ に静的書き出し
```

`pnpm build` は OG 画像に使う日本語フォントを Google Fonts から取ってくる
(必要な字だけの部分集合・数 KB)。取得できなかったときはリポジトリに置いた
欧文の部分集合([`src/assets/shippori-latin.woff`](src/assets/shippori-latin.woff)・7.7KB)に
落として、欧文だけの OG 画像を焼く。ネットワークが無くてもビルドは止まらない。

## 技術

Next.js 15 (App Router・静的書き出し) / React 19 / TypeScript / Tailwind CSS v4 /
Vitest。サーバ関数を持たないので Vercel 上で Function 実行は発生しない。

## 既知の限界

- **「今月の菓子」の初期値はビルドした月**。静的書き出しではサーバが知る「今」が
  それしかない。実際の月がずれていたときだけ、マウント後に差し替える
  ([`src/components/SeasonalNow.tsx`](src/components/SeasonalNow.tsx))
- 明暗は切り替えない。行灯の色に振った一枚の配色に決め打ちしている
