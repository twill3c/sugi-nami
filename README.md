# そば菓子 杉なみ — sugi-nami

長野県戸隠の古民家で、そば粉の菓子だけを出す店の Web サイト。日本語と英語。

> **このサイトは架空の店舗です。** ポートフォリオとして制作したもので、実在する店舗・
> 住所・連絡先ではありません。実在店と誤認されないよう、全ページのフッタ・お品書き・
> 略図・構造化データの四箇所でその旨を明示しています。

本番: https://sugi-nami.vercel.app ・ English: https://sugi-nami.vercel.app/en

## 何を見せる作品か

写真素材を一枚も使わずに、飲食店のブランドサイトが成立するかを試している。

- **図像はすべて SVG** — 杉並木・そばの実・そばの花・雪輪・古民家の切妻・道のりの略図・
  改修前後の間取り。乱数を使わず式で形を決めるので、静的書き出しと再描画で必ず同じ絵になる
- **配色は古民家の内側から** — 白いカフェサイトではなく、障子ごしの光と行灯の色で組む
- **情報の出所をひとつに** — 営業時間は [`src/data/shop.ts`](src/data/shop.ts)、
  お品書きは [`src/data/menu.ts`](src/data/menu.ts)、家の来歴は
  [`src/data/story.ts`](src/data/story.ts) だけが持つ。
  ヘッダ・フッタ・カレンダー・構造化データはすべてそこから組み立てる
- **JS が無くても全文が読める** — お品書きの絞り込みは「除く」方向にだけ効き、
  カレンダーは三か月ぶんが HTML に焼いてある

## 構成

| ルート | 英語版 | 中身 |
|---|---|---|
| `/` | `/en` | 表・今月の菓子・店のこと・道のりの要約 |
| `/menu` | `/en/menu` | お品書き(通年 7 品 + 季節 8 品)、アレルゲンの絞り込み |
| `/story` | `/en/story` | 家の年表・改修前後の間取り・残したもの |
| `/calendar` | `/en/calendar` | 三か月ぶんの営業日、休みの決まり |
| `/access` | `/en/access` | 道のりの略図、行き方、営業、建物のこと |

## 二言語のつくり

**翻訳は別ファイルの辞書に切り出さず、`{ja, en}` の対で原文の隣に置く。**
辞書に切り出すと「日本語だけ直して英語が古いまま」が起きるため。
`menu.test.ts` / `story.test.ts` が、英語が空でないこと・日本語のままでないこと
(仮名や漢字が残っていないこと)を全項目について確かめる。

`<html lang>` をページの言語に合わせて出すために、**root layout を二つ持っている**
([`app/(ja)/layout.tsx`](src/app/\(ja\)/layout.tsx) と
[`app/(en)/layout.tsx`](src/app/\(en\)/layout.tsx))。
静的書き出しでは layout が経路を読めないので、ルートグループで分ける以外に
正しい lang を出す手立てがない。言語の切り替えはページ遷移になる。

## そばアレルギーの扱い

全品にそば粉が入る店なので、**そばは品ごとに書かない**。書き忘れた品が安全に見えて
しまうため、店全体の注意書き一本に寄せている。品ごとに持つのは「そば以外に何が
入るか」だけ。この設計は [`src/data/menu.test.ts`](src/data/menu.test.ts) で固定してある。

## 営業日の計算

曜日の定休・冬期の短縮・毎年の休みを重ねて日ごとの状態を出す
([`src/lib/calendar.ts`](src/lib/calendar.ts))。
毎年の休みは西暦を持たず月日だけで書くので、年が変わっても古びない。
**年をまたぐ休み(12/29 → 1/3)は、素朴な範囲比較では一日も当たらない。**
月日を数値化して、`from > to` のときは内と外を入れかえて判定している。

## 開発

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # データ・構造化データ・営業日の検査(59 件)
pnpm typecheck
pnpm build      # out/ に静的書き出し
```

`pnpm build` は OG 画像に使う日本語フォントを Google Fonts から取ってくる
(必要な字だけの部分集合・数 KB)。取得できなかったときはリポジトリに置いた
欧文の部分集合([`src/assets/shippori-latin.woff`](src/assets/shippori-latin.woff)・21KB・
ASCII 全部)に落として、欧文だけの OG 画像を焼く。ネットワークが無くてもビルドは
止まらない。

## 技術

Next.js 15 (App Router・静的書き出し) / React 19 / TypeScript / Tailwind CSS v4 /
Vitest。サーバ関数を持たないので Vercel 上で Function 実行は発生しない。

## 既知の限界

- **「今月の菓子」と営業日カレンダーの初期値はビルドした月**。静的書き出しでは
  サーバが知る「今」がそれしかない。実際の月がずれていたときだけ、マウント後に
  差し替える([`SeasonalNow.tsx`](src/components/SeasonalNow.tsx) /
  [`CalendarGrid.tsx`](src/components/CalendarGrid.tsx))
- 明暗は切り替えない。行灯の色に振った一枚の配色に決め打ちしている
- 大雪による臨時休業はカレンダーに出ない(規則にできないため、注意書きで補っている)
